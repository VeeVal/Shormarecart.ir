# Support

ShomareCart is pre-release and does not yet provide a hosted payment-detail service.

- Use GitHub Issues for reproducible bugs and accepted feature proposals.
- Use GitHub Discussions, when enabled, for product questions and early ideas.
- Read the [project constitution](./.specify/memory/constitution.md) and the
  active feature specification before asking an implementation question.
- Follow [SECURITY.md](./SECURITY.md) for vulnerabilities; never disclose them publicly.

In Iran, sharing your destination card number with an intended payer is a normal
part of receiving a card-to-card transfer. The card number alone is not an
authentication secret and cannot authorize an outgoing payment.

Even so, support requests are unrelated public or semi-public contexts. Use a
fictional card number and recipient name when demonstrating a problem. Never
post PINs, banking passwords, CVV2 values, expiration dates, OTPs, account
balances, transaction information, or other confidential banking data.
